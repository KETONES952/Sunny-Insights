# ☀️ Sunny Insight

**Making solar energy easier to understand.**

Sunny Insight is an educational website designed to help people understand solar energy, how solar power systems work, and the important factors to consider when exploring solar energy solutions in South Africa.

The project combines my interest in science and technology with my goal of making technical information more accessible and practical.

## 🌍 About the Project

Solar energy is becoming increasingly important in South Africa. However, understanding how solar power systems work and deciding which factors matter when considering solar energy can be challenging.

Sunny Insight aims to make this information easier to explore through a simple, user-friendly website.

### Key Features

- **Home:** An introduction to solar energy and the purpose of Sunny Insight.
- **How It Works:** An overview of how solar energy systems generate and supply electricity.
- **Considerations:** Important factors to understand when exploring solar energy solutions.
- **FAQ:** Answers to frequently asked questions about solar energy.

## 🚀 Getting Started

To run the project locally, you will need [Node.js](https://nodejs.org/) and npm installed.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub username and repository name.

### 2. Enter the project directory

```bash
cd YOUR-REPOSITORY
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
